# DramaDizilerim CloudStream

Kişisel CloudStream eklenti projesi.

## GitHub
Repository: https://github.com/bequeth112448/cloudstream

## Build
GitHub Actions etkinleştirildiğinde push sonrası otomatik build yapılabilir.

Manuel:
- Windows: `gradlew.bat DramaDizilerimProvider:make`
- Linux/macOS: `./gradlew DramaDizilerimProvider:make`

## CloudStream repository URL
`https://raw.githubusercontent.com/bequeth112448/cloudstream/builds/plugins.json`

## Not
Eklenti, bölüm sayfasındaki herkese açık embed referansını CloudStream extractor sistemine aktarır. Token çözme, token üretme veya erişim kontrolü atlatma içermez.
